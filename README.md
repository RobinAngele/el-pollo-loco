A fun, browser-based 2D jump-and-run platformer. Help Pepe defeat the crazy chicken boss by collecting coins, throwing bottles, and mastering the art of jumping!

## ✨ Features

- 🎮 **Keyboard Controls** — move, jump, throw with intuitive keys
- 🪙 **Collectibles** — coins & bottles to fight enemies
- 🐔 **Enemy AI** — regular chickens + final boss with unique behavior
- 📱 **Responsive** — desktop & mobile with adaptive controls
- 🔊 **Sound FX** — immersive audio, toggle on/off
- 🖥️ **Fullscreen Mode** — enhanced gameplay

## 🕹️ Controls

| Key | Action |
|---|---|
| ← → | Move left / right |
| ↑ | Jump |
| **T** | Throw bottle |
| **B** | Exchange 1 coin → 1 bottle |

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Rendering | **Canvas API** |
| Logic | **JavaScript** (OOP, ES6+) |
| Structure | **HTML5**, **CSS3** |
| Architecture | Class-based: Character, Enemies, World, Collision, UI |

## 📁 Project Structure

```
├── models/       # Game object classes (character, enemies, world)
├── js/           # Core game logic & controllers
├── levels/       # Level configuration
├── audio/        # Sound effects & music
├── img/          # Game graphics & sprite animations
├── index.html    # Entry point — open in browser to play!
└── styles.css    # Game UI styling
```

## 🚀 Quick Start

No build step, no dependencies:

```bash
git clone https://github.com/RobinAngele/el-pollo-loco.git
cd el-pollo-loco
open index.html   # or just double-click it!
```
